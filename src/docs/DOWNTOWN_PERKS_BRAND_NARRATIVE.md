# Downtown Perks Brand Narrative

## Canonical Frame

Downtown Perks is the neighborhood operating layer for downtown living.

The map is the interface to a live downtown system connecting residents, partners, properties, and operators around local visibility, movement, access, and action.

## What It Is

Downtown Perks is a map-first local operating system for downtown residents and the partners, properties, and operators that shape the district around them.

It is not a directory, coupon product, tourism page, hospitality brochure, or generic SaaS dashboard.

## Message Hierarchy

1. Map-native product
2. Neighborhood operating layer
3. Resident decision utility
4. Property and access integration
5. Partner performance surface
6. Operator control and intelligence

## Audience Framing

Residents use Downtown Perks to discover nearby places, events, and perks, then save, RSVP, redeem, and move through downtown with less friction.

Partners use Downtown Perks to manage offers, campaigns, visibility, conversion signals, and local intent.

Properties use Downtown Perks to extend building value into the neighborhood and turn resident onboarding into a map-native entry point.

Operators use Downtown Perks to approve content, manage districts, monitor quality, and understand platform performance.

## Voice

Write like a product that already belongs downtown.

Use direct, useful, local language. Avoid vague claims, salesy phrasing, generic discovery copy, and perks-first messaging.
