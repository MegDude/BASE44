# Source and rights notes

This package contains actual sourced venue/business imagery, not synthetic placeholders.

Important: public availability is not the same thing as a reuse license. Before publishing these assets in production, advertising, paid media, or client-facing materials, confirm usage rights with the venue/business or the listed rights holder.

## Venue-specific notes

- **Las Perlas**: The official Las Perlas site was used as the primary brand reference. Its direct Wix image assets were available as AVIF in this environment, which could not be saved by the download tool. The included downloadable JPGs come from The Venue Collective Las Perlas listing associated with event booking. Treat these as approval-needed before production use.
- **Pelon’s**: Images came from the official Pelon’s website; the CDN served the files as WebP.
- **Scholz Garten**: Images came from the official Scholz Garten site/gallery. The available owned assets are largely historical/brand imagery. For a more contemporary beer-garden card, request a current patio/bar image directly from Scholz.
- **24 Diner**: Images came from the official 24 Diner gallery; the CDN served the files as WebP.
- **Aris**: Images came from the official Aris website.
- **ATX Cocina**: Images came from the official ATX Cocina gallery; the CDN served the files as WebP.

See `asset_manifest.csv` or `asset_manifest.json` for exact source URLs and source-page references.
